# Jarvis Agents

Dieser Bereich enthält alle spezialisierten KI Mitarbeiter von Jarvis 3.0.

## Erste Agenten

- Manager Agent
- Research Agent
- Quality Control Agent
- Builder Agent

## Grundregel

Jeder Agent hat eine klar definierte Rolle, eigene Aufgaben, eigene Werkzeuge und feste Qualitätskriterien.

Jarvis Core entscheidet, welcher Agent für eine Aufgabe eingesetzt wird.
